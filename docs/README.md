# Harvi Documentation

This directory contains the auto-generated documentation for the Harvi application. 
The documentation is extracted directly from the source code, database migrations, and schemas to ensure it always accurately reflects the actual implementation.

## Generated Documents

The `docs/generated/` folder contains 9 key documentation files:

1. **[Data Dictionary](generated/DATA_DICTIONARY.md)** - SQL schemas, Zod validation, and drift detection.
2. **[Cache Map](generated/CACHE_MAP.md)** - AsyncStorage and SecureStore keys, operations, and namespace.
3. **[Offline Behavior](generated/OFFLINE_BEHAVIOR.md)** - Offline capabilities, Sync Pipeline, and Cache Fallbacks.
4. *(Other docs are dynamically generated by their extractors in `docs/extractors/`)*

## Usage

To regenerate the documentation, run the orchestrator script:

```bash
node docs/generate.js
```
Or via npm/pnpm:
```bash
pnpm run docs:generate
```

## Governance

A Continuous Integration (CI) verification script ensures that the checked-in documentation matches the codebase.
```bash
node docs/verify.js
```
If the code is updated but the docs are not regenerated, `verify.js` will exit with a non-zero code and fail the CI build.
